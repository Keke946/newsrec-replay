# NewsRec Replay：中文导读

[英文首页](../README.md) · [文档索引](README.md)

这是一个从旧新闻推荐资源出发、独立重构的CPU推荐系统项目。完整实验资源包含111万余条训练点击、364,047篇文章；公开仓库提供代码、协议、汇总结果和无需原始数据的演示。

## 一条明确的主线

数据审计与时间约束 → 趋势/历史候选 → 15项共享特征与LightGBM排序 → 不可变模型版本与定时切换 → 批次API → 追加日志 → JSON快照恢复。

## 主要结论

- **最终准确率未证实提升。** 固定对照HR@5为29.3386%，事前选定的6小时刷新策略为29.3325%，114,477个请求净少7次命中，用户簇区间跨零。开发/原验证的增益没有延续，没有再用最终结果调参。
- **回放输出有完整核对。** 原验证114,855个请求的Top10顺序、历史与模型截止匹配；持久恢复的真实检查覆盖16,315个请求和两次重启。这是不同范围的检查，不混为全量持久压测。
- **快照恢复有单次配对证据。** 同一真实日志前缀上30.58秒降到8.75秒，状态及后103条响应完全一致；不是生产SLA，日志仍保留并扫描。
- **代码可独立运行。** v1核心102项验收零跳过；独立解压的公开源码也通过检查和合成演示。合成演示验证机制，不提供准确率结论。

双塔、序列、冷启动、内容融合和ANN保留为研究支线，不能全部写成已部署的提升。服务采用预计算模型回放，没有在线训练worker；真实到达时间未知，没有线上CTR或A/B收益结论。

原始数据、权重、逐请求结果和购买教程不在公开仓库中。MIT只覆盖本项目的新实现。
